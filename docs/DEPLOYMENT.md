# Deployment Preparation

The configured local stack is MySQL 8.4, Spring Boot API, and a static React frontend configured through environment variables. Docker Compose uses a new named MySQL volume, readiness health checks, and Flyway migration on startup. The legacy PostgreSQL volume declaration is retained so an existing Docker volume is not removed. `.env.example` contains placeholders only. The Compose file has not been executed because Docker is unavailable. For production, terminate TLS at a trusted proxy/host, configure strict CORS, managed MySQL backups, secret management, monitoring, retention, and migration rollback procedures. Migration of the existing PostgreSQL data into MySQL remains pending and requires a verified import procedure.

No deployment is currently verified. Docker is unavailable in the initial environment inspection. A live environment requires external hosting, DNS, TLS, database, and secret configuration and must be independently verified before being called deployed.
